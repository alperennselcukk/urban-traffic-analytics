# 🏙️ UrbanTraffic-IST: Şehir İçi Trafik Gecikme ve Tahmin Analizi

Bu proje, metropol trafiğindeki yoğunlukları ve yolculuk sürelerindeki sapmaları makine öğrenmesi algoritmalarıyla tahmin eden uçtan uca bir veri bilimi çalışmasıdır.

![Dashboard](dashboard.png)

## 📌 Proje Özellikleri
- **1,200 Senaryoluk Veri Simülasyonu:** Zirve saatler (Rush Hour), hava şartları, kaza ve yol çalışması dinamikleri.
- **Model Karşılaştırma:** Çoklu Lineer Regresyon ve KNN Regressor ($R^2$, RMSE, MAE metrikleri).
- **Executive Dashboard:** `GridSpec` ile oluşturulmuş KPI kartları, Donut Chart ve Violin Plot analizleri.

## 💻 Kullanılan Teknolojiler
- Python 3.x
- Pandas, NumPy
- Scikit-Learn
- Matplotlib, Seaborn
